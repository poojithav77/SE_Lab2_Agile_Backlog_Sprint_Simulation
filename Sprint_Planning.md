## Sprint Activities

1. Sprint Planning – Select tasks for the sprint.
2. Daily Scrum – Discuss progress and blockers.
3. Development – Implement selected features.
4. Sprint Review – Demonstrate completed work.
5. Sprint Retrospective – Identify improvements.

## Definition of Done
- Requirements are implemented.
- Acceptance criteria are satisfied.
- Basic testing is completed.
- Code is reviewed.
- Changes are integrated.

## Conclusion
Sprint planning divides project work into manageable tasks and helps the team achieve a defined sprint goal.
