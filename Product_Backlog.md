# PRODUCT BACKLOG – SKILLPATH

## User Stories

| ID | User Story | Priority | Story Points |
|---|---|---|---:|
| US-01 | As a student, I want to register and log in so that I can access my account. | High | 3 |
| US-02 | As a student, I want to create my profile so that my recommendations can be personalized. | High | 3 |
| US-03 | As a student, I want to enter my current skills so that the system can identify my capabilities. | High | 2 |
| US-04 | As a student, I want personalized skill recommendations so that I can achieve my career goals. | High | 5 |
| US-05 | As a student, I want to track learning progress so that I can monitor my development. | Medium | 3 |
| US-06 | As an administrator, I want to manage learning resources so that students can access useful materials. | Medium | 5 |

## Acceptance Criteria

**US-01:** Users should be able to register and log in with valid credentials.

**US-02:** Students should be able to save and update profile information.

**US-03:** Students should be able to add and update their skills.

**US-04:** The system should display recommendations based on skills and career goals.

**US-05:** Students should be able to mark learning activities as completed.

**US-06:** Administrators should be able to add, edit, and delete learning resources.

## Conclusion
The product backlog organizes project requirements into manageable user stories with priorities and estimated effort.
