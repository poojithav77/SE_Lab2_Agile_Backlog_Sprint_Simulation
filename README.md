# SOFTWARE ENGINEERING LAB 2
## Agile Backlog Creation and Sprint Simulation

**Project Name:** AI-Powered Upskilling Recommendation and Automation System (SkillPath)

### 1. Aim
To understand Agile project management using Jira by creating a product backlog, writing user stories, assigning priorities and story points, and planning a sprint.

### 2. Objectives
- Understand Agile and Scrum methodology.
- Create a product backlog.
- Write and prioritize user stories.
- Estimate tasks using story points.
- Plan and organize a sprint.
- Understand Scrum board workflow.

### 3. Project Overview
SkillPath is an AI-powered upskilling recommendation system designed to help students identify skill gaps, receive personalized learning recommendations, create learning roadmaps, and track their progress.

### 4. Agile Methodology
The project follows the Scrum framework, which organizes development into short iterations called sprints.

### 5. Tools Used
- Jira – Agile project management.
- Scrum – Agile framework.
- GitHub – Project documentation and version control.

### 6. Deliverables
1. Product Backlog
2. User Stories
3. Story Point Estimation
4. Sprint Planning
5. Scrum Workflow

### 7. Conclusion
This lab demonstrates how Agile project management helps organize software development through backlog management, prioritization, sprint planning, and continuous progress tracking.

**Note:** The backlog and sprint details in this repository are prepared examples. They have not yet been executed in a live Jira workspace.
